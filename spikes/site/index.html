Which tree viewer for gbif.org?

Datasets can include a phylogeny, and gbif.org should let people explore it and link its tips to occurrences. We compared existing libraries against 20 criteria and are testing the shortlist in a real browser. Every demo below is styled with the GBIF design tokens, which is itself a test of how far each library can be styled.

Manual Playwright probes used for the Reactree write-up (not part of the runner). Run from `spikes/` so `playwright-core` resolves, with `npm run dev -- --port 5308` running in `spikes/reactree/`. `scale2.mjs <yule-1000|yule-5000|yule-10000|cat-1000|cat-2000|cat-2700|cat-3500|cat-4000|cat-5000>` needs trees generated with `python3 -I data/synthetic/generate.py --out $S/gen --sizes 5000 --shapes yule` (and caterpillar sizes) and `S=<scratch dir>` set. `d8.mjs` search, collapse, export, Ctrl+F; `d10.mjs` fuzzy FASTA match and mount/unmount heap; `d12.mjs` zoom clamp, search keystroke cost, keepBrowserFind.
Numbers are in `manual-probes.json`. Machine: 4 CPU Xeon 2.8 GHz, headless Chromium 141 without GPU, shared with two other agents (load average 2 to 7), so treat times as upper bounds.

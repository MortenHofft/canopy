# Hand-made edge-case files

**These files are hand-written by the repo authors for testing parsers/viewers. They are NOT real data**
and carry no scientific meaning (species names are real only to make them readable). Licence: CC0 1.0.
Several are validated by `scripts/treecheck.py`.

| File | Tests |
|------|-------|
| `multi-tree-translate.nex` | NEXUS with TAXA + TRANSLATE blocks, three trees, `[&R]` / `[&U]` flags, quoted labels with spaces, parentheses and doubled apostrophes (`'O''Brien''s fox'`), internal labels, numeric support on internal nodes (`95`), polytomy, a tree without branch lengths |
| `quoted-labels.nwk` | Newick quoted labels, `''` escape, a comment `[&note=...]` after a label |
| `polytomy-missing-lengths.nwk` | 5-way polytomy, edges with no length, zero lengths, a **negative** length, internal and root labels |
| `unrooted-trifurcating-root.nwk` | Unrooted tree written with a trifurcating root |
| `internal-labels-support.nwk` | Internal node labels that are support values (0.95, 100) mixed with true names (`node_EF`) and a root label |
| `tree.nhx` | NHX tags `S` (species), `T` (taxon id), `D` (duplication), `B` (bootstrap); species with spaces |
| `caterpillar-20000.nwk.gz` | Fully unbalanced 20,000-tip tree (nesting depth 19,999): breaks recursive parsers/renderers. Generated by `scripts/make_caterpillar.py 20000` |
| `auspice-mini.json` | Smallest useful Auspice v2 JSON: `node_attrs` with `div`, `num_date` (+confidence), categorical `country` with confidence map, mutations in `branch_attrs`. Branch length = `div(child) - div(parent)` (substitutions), whereas `num_date` gives dates; there is no `branch_length` field |
